# Nirvana

A student wellbeing prototype for daily reflection, guided conversation, and peer connection. The demo uses sample content and local interactions; it does not provide clinical care or save check-ins.

## Run locally

Requirements: Node.js 18+ and npm.

```sh
npm install
npm run dev
```

Vite prints the local preview URL after startup. Use `npm run build` to create a production bundle or `npm run preview` to preview that bundle locally.

## What’s in the prototype

- A responsive landing page introducing the Nirvana concept
- A sample wellbeing dashboard with mood check-in, reflection chat, community posts, progress, and resource sections
- Responsive navigation for desktop and mobile

## Stack

React, TypeScript, Vite, Tailwind CSS, shadcn/ui, and Lucide icons.

## Important

Nirvana is a product prototype for reflection and peer support. It is not a medical service, diagnosis, or emergency resource. The current interactions are illustrative and should not be used for crisis support.
